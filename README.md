## The pitch

> The Sock Tribunal is a washing machine that holds a tiny trial after every wash, cross-examines the dryer under oath, and sentences it to return your missing sock with a handwritten apology.

One sentence, 190 characters. It names the tiny everyday annoyance (the
sock the dryer eats), the ridiculous invention (a washing machine that
runs a courtroom), and its silly mechanism (a trial, a cross-examination
under oath, and a sentence of return-plus-handwritten-apology).

## How it works

`main.py` (Python 3, standard library only) validates that the pitch is
exactly one sentence of 1–220 characters and writes it verbatim to
`/output/entry.txt`. The output is deterministic: byte-identical on every
run.

Run it locally:

```sh
python3 main.py
cat /output/entry.txt
```
